# Neon Dashers

An original, browser-playable rhythm-platformer remake inspired by the dash/jump genre.

## Play

Open `index.html` locally or use GitHub Pages.

## Controls

- Click or tap
- Press Space or Arrow Up

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save, then wait for the Pages URL.
